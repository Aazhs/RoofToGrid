# Proposed: Inverter Monitoring & Live Solar Telemetry

## Overview

A major risk for residential solar adopters is inverter downtime or module degradation going unnoticed for months. RoofToGrid plans to bridge that gap through unified inverter monitoring. **No live inverter provider is connected in the current product; monthly readings are entered manually.**

---

## Supported Inverter Ecosystems

1. **Growatt** (`ShinePhone` / `ShineServer` OpenAPI)
2. **SolarEdge** (`Monitoring API` / Webhook integration)
3. **Deye / Solarman** (`Solarman Smart Cloud` API)
4. **Enphase Energy** (`Enlighten Systems API v4`)
5. **Havells Enviro** (`Solar Cloud API`)

---

## Planned metrics

| Metric | Unit | Description |
|---|---|---|
| **Current Output** | kW | Instantaneous power generated by rooftop array |
| **Daily Yield** | kWh | Total energy generated today |
| **Monthly Yield** | kWh | Cumulative energy generated during current billing cycle |
| **Lifetime Generation** | kWh | Total historical system output since commissioning |
| **Performance Ratio (PR)** | % | Ratio of actual generation to theoretical output based on local solar irradiance |
| **Grid Export** | kWh | Net energy sent back to DISCOM via bi-directional net meter |

---

## Performance Ratio (PR) Health Engine

The system continuously benchmarks generation against expected seasonal insolation:
- **PR > 80%**: `HEALTHY` — System performing at or above design expectations.
- **PR 70% – 80%**: `WATCH` — Potential minor soiling or slight seasonal clipping. Recommends cleaning cycle.
- **PR < 70%**: `UNDERPERFORMING` — Significant string clipping, hotspot, or inverter fault. Triggers automated installer alert.

---

## Security & Cloud Credentials
- Homeowners provide read-only Plant IDs and API tokens.
- No remote write or inverter shutdown privileges are requested or stored.
