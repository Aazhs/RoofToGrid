# Proposed: Multi-Language & Regional Localization

Status: Planned; the current product is English-only.

RoofToGrid should eventually support Hindi, Gujarati and Marathi in addition to English. The previous partial
translation switcher was removed because translating only navigation and hero copy created a misleading and
inconsistent experience.

Localization should return only when:

1. Every string in the public calculator and four-stage demo is in a message catalogue.
2. Solar terms retain a plain-language regional gloss.
3. Currency, numerals and units remain unambiguous.
4. The full critical path is reviewed by a native speaker.
5. English remains available alongside translated regulatory terms.

Language preference may be stored locally, but no locale should be advertised until the complete planning and
quote-comparison journeys are translated.
